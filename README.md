# The Positive Press Global

Phase 1 website starter. The full Next.js site and supporting editorial/brand files will be added in subsequent commits.

## Run locally
Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy
Import this repository into Vercel, select Next.js and use `.` as the root directory.

## Editorial principle
AI may assist discovery and drafting, but every article requires human approval before publication. Do not assume RSS access grants republication rights.
